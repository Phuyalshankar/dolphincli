Installation

Add DolphinCSS to your project via NPM or CDN.

npm install dolphincss@latest
import 'dolphincss/dist/dolphin-css.css'
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/dolphincss/dist/dolphin-css.css">

Theming

Switch between light and dark modes with a single attribute.

document.documentElement.setAttribute('data-theme', 'dark');

Accordion

What makes DolphinCSS unique? ▼
It's built on Tailwind principles but fully standalone, with glassmorphic utilities and no JS dependencies.
Can I customize colors? ▼
Yes! All variables are CSS custom properties – override --color-primary, etc.
